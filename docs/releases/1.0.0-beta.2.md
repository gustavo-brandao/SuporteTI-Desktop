Prévia de correção do **Suporte TI Gráfico**, edição portátil para **Windows x64** baseada no [Suporte TI para terminal](https://github.com/gustavo-brandao/SuporteTI).

## Correção

**Computador → Problemas de dispositivos** mantém o código de problema quando um dispositivo não tem nome cadastrado no Windows. A lista usa o identificador PnP quando disponível.

## Download

Baixe **SuporteTI-Grafico-1.0.0-beta.2-win-x64.zip** em **Assets**, extraia a pasta completa e abra **Suporte TI Grafico.exe**. O arquivo **.sha256** acompanha o ZIP para conferência de integridade.

Esta beta está sem assinatura Authenticode. Os cenários com reparos reais, reinicialização, UAC com outra conta e execução por compartilhamento estão no [roteiro de homologação](https://github.com/gustavo-brandao/SuporteTI-Desktop/blob/v1.0.0-beta.2/Suporte%20TI%20Grafico/Testes/HOMOLOGACAO.md).
