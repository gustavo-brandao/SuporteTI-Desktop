Prévia portátil para Windows x64 com otimização de resultados e controle do encerramento de consultas.

## Novidades

- Tabelas preenchidas em lote, com altura calculada para as linhas visíveis.
- Filtro aplicado após 200 ms sem digitação. Limpar o filtro restaura os registros imediatamente.
- Avisos, códigos clicáveis, cópia e logs preservados, incluindo os dados ocultos pelo filtro.
- Consultas não elevadas com Job Object próprio e encerramento de processos filhos ao concluir, cancelar ou atingir o prazo.
- Leitura limitada da saída do PowerShell para conter respostas excessivas.
- Separação da projeção dos dados e da apresentação da tabela, com testes de regressão.

Na comparação local com a beta.7, a mediana para preencher 1.000 campos sintéticos passou de 1.387 ms para 42 ms, e a sequência de seis alterações do filtro passou de 6.707 ms para 251 ms. São três repetições no mesmo ambiente, sem generalizar o ganho para consultas do Windows, abertura ou memória. [Medições e método](https://github.com/gustavo-brandao/SuporteTI-Desktop/blob/main/docs/DESEMPENHO-beta8.md)

## Download e validação

Baixe **SuporteTI-Grafico-1.0.0-beta.8-win-x64.zip**, confira o arquivo **.sha256** e extraia a pasta completa. O pacote inclui o runtime .NET e usa o Windows PowerShell 5.1 da máquina.

Esta prévia não tem assinatura Authenticode. A sessão não teve permissão para acessar o Hyper-V; manutenção real em VM, conta administrativa distinta, Windows 10, UNC assinado, DPI e alto contraste continuam pendentes. A beta.8 não declara homologação completa nem versão estável.
