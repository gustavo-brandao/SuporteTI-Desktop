Prévia de correção da saúde dos discos, portátil para Windows x64.

## Correção

A leitura de desgaste ausente podia chegar à interface como um objeto vazio e provocar a mensagem de resposta JSON inválida. O coletor agora envia número finito não negativo ou null. Valores acima de 100% continuam disponíveis como medição de desgaste.

## Testes

A suíte passa a executar a consulta real de discos com as dependências SMART. Sete cenários cobrem objeto vazio, null, fração, desgaste acima de 100%, NaN, infinito e número negativo.

O verificador do ZIP oferece a opção **-Janela -Uac** para consultar a saúde dos discos pelo processo administrativo. O consentimento é dado no diálogo do Windows.

Passaram 72 testes gráficos, 13 simulações de intervenção e a regressão CLI com 204 casos. O ZIP extraído passou na consulta administrativa de discos pelo UAC, nas exportações e na navegação.
